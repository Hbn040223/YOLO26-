# YOLO26-iDisp 聚合头诊断与验证方案（修订版）

**基线**　`experiment/mobilenetv2-050@b6c93ff`，MobileNetV2 0.5×，正式权重 `best_r2.pt`。本次交付为实验方案。先完成等价后端对照、精度边界对照和固定框诊断，再依据结果选择一个结构变量。

**目标**　确定 9 对框时局部聚合的真实耗时和精度损失来源。先验证 `bmm`、FP32 聚合、跳过全有效空间掩码、GT-RoI／Pred-RoI 四项，再决定校准搜索范围或将聚合隐藏宽度从 32 缩到 24。

## 0. 前置交付物　GT 左右框核验清单

- [ ] 由实验执行者产出首批 **8–12 帧开发诊断清单** `D-gt-manifest-development.json`，并随附核验记录。在 D 正式统计前冻结清单和 SHA-256。优先纳入 `training/000004_10` 的 GT 13 与候选 `9486`，以及 `training/000058_10` 的 GT 3 与候选 `9524/9642`。后者是同一 GT 的两个候选，清单中 GT 仅登记一次。其余帧覆盖宽框、遮挡、截断和距离边界。
- [ ] 每帧记录数据划分、帧 ID、左右原图、左图实例图、视差真值、`bf_px_m` 与 `cx_delta_px`。每实例记录 GT ID、类别、左右框、右框来源和 `right_box_verified`。候选 ID 写在诊断记录中。核验时确认左右图为同一时刻、框指向同一个可见实例，记录审核状态、遮挡或截断情况及排除原因。
- [ ] 投影生成的右框在人工核验前只进入 smoke 清单。缺可靠右框的实例保留诊断记录，正式匹配与结构决策使用核验通过的分母。独立集另建清单，排除训练帧、开发选模帧和上述诊断样本。A–C 可与清单准备并行，D 的正式统计和 §4 的结构决策以核验清单为前提。

## 2. 冻结实验输入与计时边界

- 固定权重 SHA-256、代码提交、OpenStereo 提交、逐帧标定和样本清单。保留全图、`fixed_56`、33 档、score 0.48、同类 paired NMS IoU 0.50、top-K 500、15 m 初筛与 10 m 输出。0.48 是现有板端实验值。
- 板端固定 Orin NX 25 W、GPU 频率配置、输出字段与预热方式，记录版本、温度、频率。严格数值对照关闭 CUDA matmul 和 cuDNN TF32。生产精度和默认 TF32 的测速另跑一组，并在同一对照内固定相应设置。
- 诊断帧分清数据划分。用训练帧 `000004_10`、`000005_10` 测嵌套 6/9 对，`000058_10` 测轻载 2 对，测试集 `000000_10` 测零对短路。根据实际入口按分数降序、ID 升序固定框，6 对是 9 对的子集，缺负载直接记录。另挑出 40 帧开发集入口对数最多的一帧检查显存。
- 每配置每负载预热 20 次，至少 60 轮交替 A/B。报告缓存 RoI 的 iDisp CUDA event 和墙钟、采样到 iDisp 输出的时间，以及插桩轮的代价体／聚合／回归。记录逐轮差值、中位数与 P95、95% 配对 bootstrap 区间（seed 17，10,000 重采样）和峰值显存。计时与 profiler 轮分开。区间跨零时记为收益未能稳定区分。
- 聚合收益按同一脚本、计时边界、精度和负载比较。整帧插桩、缓存 RoI 的 CUDA event 和独立墙钟各自保留。
- 精度先用原 40 帧冻结清单，再用独立近距样本复核。诊断、调参、验收样本分别记录。独立样本应覆盖宽车框、遮挡、截断、9–11 m 及 10–15 m 车辆，以实际样本数作分母。

## 3. 四项验证

### A. 确认 `bmm` 的输出与收益

- [ ] 固定同一份左右 RoI 特征、crop metadata 和权重，对照 `loop` 与 `bmm`。覆盖 1/2/6/9 对、左／右越界档、全无效位置与窄 RoI。逐元素比较 `valid_bins` 和代价值，FP32 代价体拟用 `atol=1e-5, rtol=1e-5`，并记录最大绝对差。
- [ ] 使用基线提交的 `--idisp-cost-backend bmm` 重跑，记录实际调用 `_rowwise_cost_volume`、提交及配置。旧 `bmm_prototype` 计时仅作历史参考。
- [ ] 用相同的整链路配置复核 40 帧。检查 iDisp 入口 ID、最终 ID、前景有效掩码和 10 m 判定一致。新增等价性硬门槛 **共同有效像素 `max(abs(Δdisp)) ≤0.02 px` 且出口框 ID 零变化**。共同有效像素为空时标缺测并报告覆盖，零框帧单独验收。保留 EPE 变化 ≤0.02 px、D1 变化 ≤0.2 个百分点作为汇总复核，逐项记录距离变化和失败帧。
- [ ] 板端对照 2/6/9 对和最大候选帧。9 对的 iDisp P50/P95 应降低，2 对的 iDisp 与整链路分别报告，显存峰值应满足设备余量。报告 0 对确认短路。通过后将 `bmm` 用作后续实验基线。轻载或大负载出现回退时保留 `loop` 回退选项。

现有脚本可先验证 `000004_10`，在基线仓库根目录运行。先设 `OPEN` 为 OpenStereo 路径，`DATA` 为 KITTI 2015 根目录。其他帧须使用其各自的标定记录。

```bash
export PYTHONPATH=src:scripts
OUT="outputs/v2-050/idisp-aggregation/$(date +%Y%m%d-%H%M%S)"
for BACKEND in loop bmm; do
  python scripts/benchmark_idisp_fixed_pairs.py \
    --openstereo-source "$OPEN" --weights outputs/v2-050/formal/best_r2.pt \
    --left "$DATA/training/image_2/000004_10.png" \
    --right "$DATA/training/image_3/000004_10.png" \
    --split training --frame-id 000004_10 --device cuda:0 \
    --bf-px-m 384.38148 --cx-delta-px 0 --score 0.48 \
    --precision fp32 --idisp-cost-backend "$BACKEND" \
    --loads 0,2,6,9 --warmup 20 --repeats 60 --profile \
    --output "$OUT/000004_10-$BACKEND.json"
done
```

分开运行的 JSON 先核对固定框 ID 和坐标。正式的后端配对区间需将两个后端放入同轮交替执行。上面的命令用于复现基准、检查各后端的分项与 9→6 对差值。

### B. 单独比较聚合 FP32 与聚合 autocast

- [ ] 任务 A 通过后固定 `bmm`。同一前端只编码一次，缓存左右 RoI、代价体、P2/P3/P4 上下文和有效档。A 组聚合用现有 FP16 autocast，B 组聚合入口及内部使用 FP32。两组在同一边界以 FP32 做无效档处理、soft-argmax、原图视差恢复和测距。循环内仅切换聚合精度。现有 `fp32` 与 `amp-fp16` 全链路模式会改变前端，适合做独立补充对照。隔离聚合需在验证阶段加一对实验入口。
- [ ] 实验入口的优先级为 **显式 `force_fp32` > `amp_aggregation=True` > 外层 autocast**。显式 FP32 在聚合作用域关闭 autocast，并在聚合入口按需转换浮点输入。回归保持上条所定的 FP32 边界。检查 `scripts/benchmark_edge_stream.py` 的运行时设置、`scripts/evaluate_edge_near10.py` 的对照模型设置、`scripts/benchmark_idisp_fixed_pairs.py` 的 AMP 基准设置。验证三处均无法覆盖显式 FP32，实际 dtype 和转换次数可在记录中复核。当前基线还需补该入口。
- [ ] 对 2/6/9 对记录每个阶段的实际 dtype、CUDA event、墙钟、峰值显存。四个 96 通道尺度逐张量记录 dtype 转换、同类型拷贝和无拷贝调用。聚合内部单列 GroupNorm、卷积、插值及掩码；CUPTI 不可用时保留算子计数和阶段事件，CUDA 子算子耗时标缺测。
- [ ] 以全 FP32 结果为精度参考，复核有效像素、EPE/D1、距离误差和近车 ID。仅在精度通过且重载 iDisp P95 与连续回放 P95 均改善时采用新精度配置。无稳定收益时保留较可靠的当前配置并上传原始对照。

### C. 仅对已知全有效的空间掩码做等价简化

- [ ] 为 `fixed_56` 的已知全有效路径设计静态开关。传播采样路径的全有效契约，省去聚合内部全 True 掩码乘法与生成较低分辨率空间掩码的池化。保留普通掩码路径供 `native_pad` 和有无效位置的输入使用。避免运行时用 GPU `.all()` 决定 CPU 分支。
- [ ] 保留代价体查找的逐视差档边界有效性、回归前 `valid_bins` 和解码器两次上采样。验证图像边缘框、最小和最大视差档、普通掩码路径，以及 0/2/6/9 对。对照聚合 logits、绝对视差、距离、前景有效性与 ID。等价性使用任务 A 的下游门槛，并记录 logits 是否逐元素相同。
- [ ] 先做 **A/A**。在同一份缓存代价体、上下文、掩码和精度下，两臂都走普通掩码路径，使用与 A/B 相同的计时和交替顺序。按负载和计时口径记录绝对配对差值的 P95，作为本轮波动参考。任务 A 中同代码跨后端的聚合分项差另列，便于识别上游变化带来的时延差。
- [ ] 再做 **A/B**。只切换掩码路径，用普通路径减跳过路径得到逐轮收益，报告 P50/P95 和配对置信区间。拟以重载聚合收益 P50 的 95% 区间下界高于同口径 A/A 绝对差 P95、且路径等价为采用条件。未跨过该线时保留原路径，记录当前收益未能稳定区分。当前基线尚需该实验开关。

### D. 同一权重的 GT-RoI／Pred-RoI 对照

- [ ] 固定 0.5× 和任务 A–C 确立的实现。GT-RoI 用同一实例的核验左右 GT 框。Pred-RoI 用模型自动产生的框，按 `frame_id + GT ID` 进行同类一对一匹配，要求左右 IoU 均 ≥0.50。缺可靠右框的样本标为诊断，投影右框可做 smoke。保留无法匹配、漏检和重复框的单独分母及去向。
- [ ] 两个 RoI 输出都投影回同一原图坐标。逐实例在共同 GT 前景且两臂都有有效预测的像素上算 EPE、D1，再各自报告对 GT 前景的覆盖率。分别统计原图掩码内侧 4 px 边缘／内部、像素平均／实例平均，以及按宽框、截断、遮挡、距离分层的结果。另报预测 Mask IoU、前景测距误差与 10 m 判定。
- [ ] 拆解裁剪先验。定义 `d0=c_l-c_r` 为实际左右裁剪起点之差，`d_center` 为**解码后的左右框中心差**。两侧未触边时 `d0=d_center+(w_R-w_L)/2`。逐实例记录中心差、宽度差项及裁剪修正 `d0-[d_center+(w_R-w_L)/2]`。检测头的原始偏移是检测点到右框中心的差，计算中心差时还需加上左框中心相对检测点的偏移。在 Pred-RoI 上记录 clamp 前后的偏移、`legacy_clamp` 触发率和分母。缺少 clamp 前输出时标缺测。使用原图视差坐标，主点差在换算距离时处理。
- [ ] 分开统计**名义半域溢出**和**逐像素无效档**。设 `s=c/w_roi`，用 `r_gt=(d_gt-d0)/s` 在两臂的同一 GT 前景分母上统计 `abs(r_gt)>16` 与超出半域的像素距离。对名义范围内且可映射到 RoI 的 GT 像素，按预先冻结的最近档映射规则核对 `valid_bins`，分开记录右采样坐标越界、空间无效和 GT 像素不在 RoI 覆盖内。报告各自分母和覆盖，逐像素边界越界不计入半域溢出。
- [ ] 保存聚合前后最优档、最优与次优差、低置信度和熵。对可靠一对一配对的实例画两张图，分别比较共同有效前景像素的预测与 GT 中位视差，以及减去同一 `d0` 后的预测与目标残差。报告样本数、斜率、截距与按帧重采样的区间。拟合作为欠修正或系统偏差的辅助证据，同时检查正确档排名。软回归可以输出分数档，整体 EPE 与网格尺寸的比值用于提出细节损失假设。
- [ ] 对 `000004_10:9486` 检查左右框、前景覆盖和聚合前后分布。已复算的裁剪先验是 39.42 px，模型前景中位视差 38.75 px，关联车辆真值约 27.29 px，所需修正约 −12.13 px、约 −2 档，落在实例的名义搜索区间内。继续核对有效档、同一 GT 的像素对齐，以及匹配峰是否在正确位置。该例的近零残差不足以确认 soft-argmax 的失效原因。把 `000005_10:9542/9584` 另列为低 IoU 近距误报，避免给错误身份计算同车距离误差。
- [ ] 复用 `scripts/evaluate_fixed_pair_features.py` 的固定 GT 框、边缘统计和有效范围输出。当前入口要求提供 1.0× 和 0.5× 两份权重，已有自动框匹配诊断。正式验证时为同一 0.5× 补齐 Pred-RoI 的逐像素对齐与评估，再汇总共同像素结果。1.0× 的同框结果可另用于特征对照。

## 4. 根据结果选择下一项

下列百分比和回归容差是本方案提出的工程判据。开始看结果前冻结口径。结论应关联逐帧证据及独立样本复核。

| 观测结果 | 下一项 |
| --- | --- |
| 固定 GT-RoI 后，同类场景有 >5% 的有效前景 GT 像素满足 `abs(d_gt-d0)/s>16`，由多个独立实例贡献。 | **先改搜索范围。** 按裁剪宽度分层检查残差尾部。初轮固定 56×56 和聚合宽度 32，只比较搜索域，并复核前景覆盖及 10 m 判定。 |
| 名义半域覆盖充分，失效集中在右采样越界、空间无效或 RoI 覆盖不足。 | 优先查裁剪和逐像素有效性，按原因复核几何。 |
| 溢出主要出现在 Pred-RoI，GT-RoI 的共同像素表现明显更好。 | 对照左右配对、解码中心差、框宽度项、裁剪修正和 clamp 触发率。根据证据决定优先复核右框回归、解码或裁剪搜索中心。保留旧范围和宽度作为对照。 |
| GT 及合格 Pred 框均有充分搜索覆盖，建议整体和关键分层都 ≥99%。冻结的精度门槛已通过，但 9 对聚合或连续 P95 仍超预算。 | **先试聚合宽度 32 → 24。** 固定 RoI、搜索、阈值、后端和上下文接口，将内部宽度从 32/64/96 改为 24/48/72。独立权重先 5 epoch pilot，再按既有 30–60 epoch 正式训练口径复核，保留基线回退。 |
| 搜索覆盖充分，但 GT-RoI 在正确几何下误差仍高，或两类证据都未稳定。 | 暂缓结构选型。比较聚合前后的正确档排名及错误区域，补样本定位匹配特征与聚合的贡献。 |

**算量预算。** 按当前 `56×56` 聚合头逐层计算 Conv2d 的 MAC。33 档、宽度 32 为 **199.1 MMAC/对**。维持宽度 32 时，13 档为 **179.1**（−10.1%），9 档为 **175.1**（−12.1%）。维持 33 档时，宽度 24 为 **126.1**（−36.7%）。这些数字只衡量聚合卷积，板端耗时仍由张量布局、算子和实际负载决定。batch 仍按最大档数分配时，仅加按实例的 bin mask 不会省掉密集聚合。改为约 stride-4 网格时宽框可能变大，应作为另一个实验单独计量。

## 5. 统一验收及产物

- 按 `A-bmm.json`、`B-aggregation-precision.json`、`C-spatial-mask.json`、`D-gt-pred-roi.json` 分开保存。每项附原始逐轮或逐实例记录、版本和设备证据。B/C 不可运行时注明具体缺失开关，D 缺独立左右标注时单列数据缺口。
- 变体精度用同一冻结 40 帧，保持近车成对召回 ≥18/23、一物一对 ≥17/23，无新增近车漏检。等价路径另要求保持当前已命中的 20 个近车 ID。独立集按实际分母复核，报告范围外像素、边缘 EPE/D1、前景覆盖、距离高估和远车误入。
- 改 `dmax`、档数或物理采样约定按独立的训练变体验收。训练会排除超出搜索范围的监督像素，因此为变体冻结训练预算、数据、选模口径和新权重，保留原 33 档／宽度 32 权重及其配置作为回退。变体与基线按同数据同指标做精度和速度回归，逐像素等价门槛用于任务 A 和 C，任务 B 按精度与时延的验收结果选择。
- 板端报告分两层。固定框测聚合和 iDisp P50/P95，连续内存回放包含归一化、传输、推理、后处理、结果回传和排队。原生工程目标为 120 秒 600/600、含排队 P95 ≤200 ms、零丢帧且零积压。覆盖 0 对、轻载和 ≥9 对。TensorRT 的 reformat 与布局拷贝作为独立实验记录。
- 决策记录注明选择的单一变量、触发证据、对照配置、失败回退，以及下一轮保留的样本和指标。
